# 🎮 Leaserwork

A fun and challenging arcade-style game built with Godot Engine!

## 📝 Description

Leaserwork is an action-packed game where players navigate through increasingly difficult obstacles. Test your reflexes and skills across multiple difficulty levels!

## ✨ Features

- **Multiple Difficulty Levels** - Start easy and work your way up to hard mode
- **Smooth Gameplay** - Optimized controls and responsive mechanics
- **Sound Effects** - Immersive audio experience
- **Clean UI** - Intuitive menu system and level selection

## 🎯 How to Play

1. Use arrow keys or WASD to control your character
2. Avoid obstacles and survive as long as possible
3. Progress through different difficulty levels
4. Challenge yourself to beat your high score!

## 🚀 Getting Started

### Prerequisites
- [Godot Engine 4.x](https://godotengine.org/download) (or compatible version)

### Installation

1. Clone this repository:
```bash
git clone https://github.com/dexterMorgaN-9/leaserwork.git
```

2. Open Godot Engine

3. Click "Import" and navigate to the cloned folder

4. Select `project.godot` and import the project

5. Press F5 to run the game!

## 🕹️ Controls

- **Arrow Keys / WASD** - Move player
- **ESC** - Pause/Menu
- **Mute Button** - Toggle sound on/off

## 🛠️ Built With

- **Godot Engine** - Game engine
- **GDScript** - Programming language
- **Aseprite** - Pixel art and sprites
