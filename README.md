# :video_game: Leaserwork
**Leaserwork** is a fast-paced arcade reflex game with **two different game modes**, each designed to test your focus, timing, and reaction speed.
:arrow_forwards: Play now: https://winter0619.itch.io/leaserwork
---
## :dart: Game Objective
Survive as long as possible by reacting quickly and avoiding failure.
Each mode challenges a different skill. There is no memorization help, only reflex.
---
## :joystick: Game Modes
### :brain: Mode 1: No-Remember Block
- Blocks appear on the screen
- React instantly without memorizing patterns
- One mistake ends the run
- Difficulty increases over time
**Focus:** Reflex & instant decision-making
---
### :red_circle::large_blue_circle: Mode 2: Red Dot Escape
- You control a **red dot**
- Move left and right to survive
- Protect the red dot from incoming **blue balls**
- Last as long as possible without collision
**Focus:** Timing, control, and precision
---
## :video_game: Controls
- **Left Arrow / A** – Move left
- **Right Arrow / D** – Move right
- **ESC** – Pause / Menu
---
## :trophy: Challenge
- Improve reaction time
- Survive longer each run
- Beat your own high score
